## 1. 为什么不能"先跑只读部分"

S39 的每一项都以"部署已完成"为语义前提：

- **SHA** 比对的是**已部署**的版本与候选版本——未部署则无可比对象
- **health / 迁移** 读的是**已部署实例**的状态
- **首页 / CSP** 检查的是**已部署站点**的响应头
- **日志 / 指标** 读的是**部署后**的运行数据
- **只读 smoke** 打的是**已部署 API**

在未部署状态下执行其中任何一项，得到的要么是旧版本的状态（会被误读为新版本已验证），要么是连接失败。**两者都比不执行更糟**——前者制造虚假验收，后者是噪音。

按标准约束「不将"页面能打开"或"健康检查通过"标为生产验收完成」，本会话拒绝产出任何形式的替代性"部分验收"。
